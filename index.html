How to redeem a Muse invite code

Updated 23 October 2026 · 3 minute read

If someone shared a Muse invite code with you, this is the official way to enter it — and the limits to know before you start. The exact reward is shown on the redemption screen for your account; it is not guaranteed by this page.

Before you start

  • Muse is currently available in the US and Canada.
  • On mobile, code redemption is available in the first 48 hours after you join Muse.
  • An account can only confirm redemption once. The entry disappears after a successful redemption.
  • Opening an invite link on its own does not redeem a code or credit a reward.

The code shared with this guide

VQR8WY

Enter the code exactly as shown. If the form reports it as invalid, used up, or revoked, that result — not this page — decides whether it can be used.

On iPhone or Android

  1. Open the Muse app and sign in.
  2. Go to Settings → Redeem token.
  3. Enter VQR8WY and confirm.
  4. Check the result shown in the app before assuming any tokens were credited.

On the web

  1. Go to muse.ai and sign in.
  2. Go to Settings → General → Usage → Redeem invite code.
  3. Enter VQR8WY and confirm.
  4. Check the result shown on the form.

If it does not work, check the obvious causes first: the 48-hour mobile window has passed, the account has already redeemed a code, the code has expired or been used up, or too many attempts have been made. Wait and read the message on the redemption screen — it states the reason.

Frequently asked questions

Where do I enter a Muse invite code?

On iPhone or Android, open the Muse app and go to Settings → Redeem token. On the web, go to muse.ai and open Settings → General → Usage → Redeem invite code.

How long do I have to redeem a Muse code on mobile?

On mobile, code redemption is available in the first 48 hours after you join Muse.

Why is my Muse redeem code not working?

Common causes: the 48-hour mobile window has passed, the account has already redeemed a code, the code has expired or been used up or revoked, or too many attempts have been made. The message on the redemption screen states the reason.

Where is Muse available?

Muse is currently available in the US and Canada.

Does opening an invite link redeem the code automatically?

No. Opening an invite link on its own does not redeem a code or credit a reward — the code must be entered and confirmed in the redemption form.

What this guide does not promise

It does not promise a specific number of tokens. Offer terms, the reward amount, and remaining invitations are set by the invitation and redemption screens for each account, and they can differ between accounts.
