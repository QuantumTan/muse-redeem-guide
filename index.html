How to redeem a Muse invite code

Updated 23 October 2026 · 3 minute read

If someone shared a Muse invite code with you, here is the step-by-step method, including how to get access from outside the US. The exact reward is shown on the redemption screen for your account; it is not guaranteed by this page.

Before you start

  • Muse is currently available in the US and Canada, so from anywhere else you need a USA connection (a VPN).
  • You need a fresh Gmail account that has not been used on Muse AI before.
  • Age verification may include a refundable $1 authorization charge.
  • Opening an invite link on its own does not redeem a code or credit a reward.

The code shared with this guide

VQR8WY

Enter the code exactly as shown. If the screen reports it as invalid, used up, or revoked, that result — not this page — decides whether it can be used.

Step by step

  1. Connect a VPN. On Android, install Urban VPN, set your location to the USA, and connect. On desktop, install the Urban VPN extension in your browser and connect to USA.
  2. Clear your browser cache. Open Google Chrome, clear your browsing data and cache, then go to the Muse AI website.
  3. Sign up. Register a fresh Gmail account that hasn’t been used on Muse AI before.
  4. Verify email and age. Enter the verification code sent to your email, then complete age verification (a refundable $1 authorization charge may apply).
  5. Redeem the code. Go to Menu → Settings → General Settings → Redeem Code, enter VQR8WY and confirm.
  6. Check the result shown on the screen before assuming any reward was credited.

If it does not work, check the obvious causes first: the VPN is not connected to the USA, the Gmail account was already used on Muse AI, the account has already redeemed a code, the code has expired or been used up, or too many attempts have been made. Read the message on the redemption screen — it states the reason.

Risk: using a VPN to change your location or signing up with extra accounts may go against Muse’s terms, and accounts can be restricted or rewards withheld. Do this at your own risk.

Frequently asked questions

Where do I enter a Muse invite code?

Go to Menu → Settings → General Settings → Redeem Code, enter the code and confirm.

Can I redeem a Muse code outside the US?

Muse is currently available in the US and Canada. The method on this page uses a USA VPN (Urban VPN) and a fresh Gmail account. This may go against Muse’s terms, so you do it at your own risk.

Do I need a new Gmail account?

The steps shared here use a fresh Gmail account that has not been used on Muse AI before.

Why is my Muse redeem code not working?

Common causes: the account is not new, the account has already redeemed a code, the code has expired or been used up or revoked, the VPN is not connected to the USA, or too many attempts have been made. The message on the redemption screen states the reason.

Does opening an invite link redeem the code automatically?

No. Opening an invite link on its own does not redeem a code or credit a reward — the code must be entered and confirmed on the Redeem Code screen.

What this guide does not promise

It does not promise a specific number of tokens. Offer terms, the reward amount, and remaining invitations are set by the invitation and redemption screens for each account, and they can differ between accounts.
